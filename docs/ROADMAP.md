# Roadmap

## P0

Concluir demonstracao navegavel com login, dashboard, cadastros, documentos, comprovantes, importacao, relatorios, seed e testes.

## P1

- Auditoria detalhada por campo.
- User management completo.
- PDF dos novos relatorios.
- Melhorias de experiencia do aluno.
- Mais filtros, paginacao server-side e busca avancada.
- Storage S3 compativel.

## P2

- Assinatura digital.
- Pix, boleto, cartao e conciliacao bancaria.
- WhatsApp.
- Aplicativo nativo.
- OCR/reconhecimento documental.
- Integracoes com instituicoes.
- White-label completo.
